🧑‍💻 Internship Task: Simple Notes App (Android Kotlin)
🎯 Objective

Build a basic Notes App where users can create, view, and delete notes.

🛠️ Requirements
1. Home Screen (Notes List)
Show a list of saved notes
Each item should display:
Title
Short description (optional preview)
2. Add Note Screen
A screen with:
Title input field
Description input field
Save button
On save → note should be stored locally
3. Delete Note
Each note should have a delete option (button or swipe)
Removing a note should update the list immediately
4. Local Storage

Use any ONE:

Room Database (preferred)
OR SharedPreferences (simple version allowed)
5. UI Requirements
Simple clean UI (no need for fancy design)
Use RecyclerView for list
Use basic Android XML layouts
🌟 Bonus (Optional)
Edit note feature
Timestamp (created date)
Empty state screen ("No notes available")
Material UI styling
⏱ Time Limit
2 hours maximum
🔍 Allowed
Google search
StackOverflow
Official Android documentation
🚫 Not Allowed
AI tools (ChatGPT, Copilot, etc.)
📦 Output Expected
GitHub repository link
Clean project structure
App should run without crashes
🧪 Evaluation Criteria
Correct use of RecyclerView
Proper local storage implementation
Code organization (activities, adapters, models)
Basic UI/UX cleanliness
Working CRUD (Create, Read, Delete)
⚡ Why this task works well
Tests core Android skills
Forces use of RecyclerView + storage
Easy to finish in 2 hours
Very easy to evaluate quickly
